# 工业人工智能测试平台

面向工业智能算法迁移与鲁棒性的全过程自动化测试工具。

## 项目目标

- 单次完整测试累计样本推理数不超过 1000 次
- 单次完整测试流程不超过 5 分钟
- 原始训练数据依赖不超过 10%
- 支持目标域无标签迁移风险评估
- 支持攻击与异常扰动鲁棒性测试
- 覆盖不少于 3 类风险或漏洞
- 漏洞定位准确率目标不低于 85%

## 主要模块

- `src/models/`：待测模型加载与统一推理接口
- `src/data/`：数据加载、预处理与样本筛选
- `src/transfer/`：迁移能力评估
- `src/robustness/`：攻击与异常扰动测试
- `src/localization/`：漏洞定位与解释
- `src/pipeline/`：自动化流程编排
- `src/reporting/`：测试结果与报告生成
- `src/utils/`：推理计数、计时、日志等公共工具

## 团队分工

- 同学 1：项目统筹、系统架构、迁移评估、推理次数优化
- 同学 2：鲁棒性测试、数据处理、可视化
- 同学 3：自动化流程、报告生成、指标采集

## 环境安装

```bash
pip install -r requirements.txt
```

## 快速运行

当前为第一版工程目录，核心功能将在第二周逐步补充。

## 协作规范

1. 不直接向 `main` 分支提交功能代码。
2. 每位成员建立自己的功能分支。
3. 修改完成后通过 Pull Request 合并。
4. 数据集、模型权重、运行结果和视频不上传 GitHub，统一存放在团队共享云盘。
